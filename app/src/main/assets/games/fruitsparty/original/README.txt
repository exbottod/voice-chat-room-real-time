KODE ASLI GAME FRUITS PARTY

FruitsParty.bundle.min.js = file asli apa adanya dari proyek Lovable
(bundle yang dipakai preview, nama aslinya routes-yJGsF3nE.js).

FruitsParty.pretty.js = isi yang sama, hanya dirapikan otomatis
(865 baris, tidak ada logika yang diubah). Semua bagian game ada di sini:
daftar buah dan nilai bayaran, aturan bonus, porsi jackpot, animasi
putaran, tombol taruhan, panel peraturan.

styles.css = kelas fp- asli dari stylesheet proyek.

Komponen sumber aslinya bernama src/components/FruitsParty.tsx (terlihat
dari data-tsd-source di HTML). Untuk mendapatkan file .tsx apa adanya,
pakai Export to GitHub di Lovable.
